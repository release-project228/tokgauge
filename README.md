# tokgauge

Analytics around public TikTok data: profiles, videos, comments and follower
growth — no account needed on the viewer side.

**Website: [https://tokgauge.com](https://tokgauge.com)**

## Example

`tiktok_growth.py` is a tiny growth report over a CSV of your own account
history (`date,followers` per line):

```bash
python tiktok_growth.py growth.csv
```

The full product lives at [https://tokgauge.com](https://tokgauge.com).
